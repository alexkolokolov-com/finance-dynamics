# Страница статьи блога «Вася и финансы»

Эталон верстки — `src/pages/FinancialPlan.tsx` (маршрут `/financial-plan`).
Новая статья собирается ТОЛЬКО из готовых блоков ниже. Не изобретать свою
сетку, отступы, цвета и размеры шрифтов.

## Каркас

```tsx
<ArticlePage title="…" description="…">
  <ArticleHero title={…} accent={…} lead={…} image={heroImg} imageAlt="…" />
  <ArticleSection><ArticleFlow>…вводные абзацы…</ArticleFlow></ArticleSection>
  <ArticleSection><ArticleFlow><ExpertQuote>…</ExpertQuote></ArticleFlow></ArticleSection>
  …разделы…
  <ArticleCta />
</ArticlePage>
```

## Блоки (`src/components/article/`)

| Блок | Назначение |
| --- | --- |
| `ArticlePage` | Каркас: шапка сайта, содержание, Varioqub, подвал, title/description |
| `ArticleHero` | H1 с курсивным акцентным хвостом + подзаголовок + обложка |
| `ArticleSection` | Смысловой раздел, принимает `id` для якоря |
| `ArticleFlow` | Колонка текста max-w-3xl; сам задаёт типографику `p`/`ul` |
| `H2` / `H3` | Заголовки разделов; `<H3 toc={false}>` исключает из содержания |
| `Pull` | Акцентная плашка с выводом (одно-два предложения) |
| `Figure` | Иллюстрация с подписью, full-bleed на телефоне |
| `ExpertQuote` | Цитата Василия с фото и подписью |
| `ArticleCta` | Финал «Давайте поговорим» + кнопка диагностики (цель + UTM) |
| `StorySection` | Истории «2/3 текст + 1/3 фото», чередование сторон |

Важно: `Figure` ставится МЕЖДУ `ArticleSection` (не внутри `ArticleFlow`),
иначе теряется full-bleed на телефоне.

## Правила текста

- Весь русский текст оборачивать в `nbsp("…")`; JSX-вставки — через `&nbsp;`.
- Тире только короткое `–`, длинных `—` в статьях не использовать; не больше
  одного тире на абзац, остальное — запятые и двоеточия.
- `<strong>` только на выводе абзаца, не на целом абзаце.
- Абзацы связные, 2–4 предложения. Никаких списков ради списков.
- Заголовки без точки в конце.

## Ритм страницы

- Чередовать: текст → иллюстрация → вывод. Иллюстрация не должна всегда
  стоять в конце пункта; ставить её по смыслу, в том числе в середине.
- `Pull` — редко, как акцент; подряд два `Pull` не ставить.
- У ключевых разделов задавать `id` на `ArticleSection` для якорей.

## Запреты (память проекта)

- Никакой «Физики финансов», физтеха, «эксперимента», школьной/тетрадочной
  графики (мел, орбиты, формулы в фоне), моноширинных капс-эйбров.
- Цвета и шрифты — только токены проекта (`bg-background`, `text-foreground`,
  `text-accent`, `font-display`, `font-body`). Никаких `text-white`, `bg-[#…]`.
- Иллюстрации в едином редакционном стиле бренда (см. `src/assets/plan-*.jpg`,
  `stress-*.jpg`): тёплая кремовая бумага, терракотовый акцент, без текста
  внутри картинки.

## Чек-лист публикации

1. Страница создана в `src/pages/<Name>.tsx` на основе
   `.agents/skills/blog-article-page/assets/ArticleTemplate.tsx`.
2. Маршрут добавлен в `src/App.tsx` выше catch-all `*`.
3. Карточка статьи добавлена в `src/data/blogPosts.tsx` (`title`, `text`,
   `cta`, `href`, обложка через `<img>` с `loading="lazy"`).
4. `title` и `description` заполнены в `ArticlePage`.
5. Проверить телефон (390px) и десктоп (1280px): содержание открывается,
   картинки не мелкие, кнопка диагностики ведёт на getcourse в новой вкладке.
6. `bunx tsc --noEmit -p tsconfig.app.json`.

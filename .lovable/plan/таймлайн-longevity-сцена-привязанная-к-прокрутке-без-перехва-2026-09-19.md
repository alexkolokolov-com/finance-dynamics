# Таймлайн /longevity: сцена, привязанная к прокрутке (без перехвата жестов)

## Замер (Playwright, 1440×900, реальная прокрутка от верха страницы)

| Сценарий | Проигранные главы |
| --- | --- |
| колесо 300px каждые 100ms | `1 → 2` (дальше страница ушла вниз, top = −38) |
| колесо 200px каждые 400ms | `2 → 4 → 6` (глава 1 пропущена, finalY 4138) |
| колесо 120px каждые 1200ms | только `6` |

Диагноз:

1. `isPinned()` (LifeTimeline.tsx:355–360) требует `rect.top <= 64 && rect.bottom >= innerHeight`. Это окно возникает только на одном значении scrollY. Жест, который приводит к сцене, тем же импульсом проносит её мимо окна — сцена не получает ни одного шага.
2. Шаг живёт 1.64s (`EXIT 260 + ENTER 480+50 + HOLD 900`), а `preventDefault` работает только пока сцена уже закреплена. За время одного шага непрерывная прокрутка успевает вывести трек `h-[180vh]` из окна закрепления, и оставшиеся главы теряются.
3. `GESTURE_GAP_MS = 140`: события тачпада/мыши с интервалом < 140ms считаются одним жестом и гасятся — при плавной прокрутке шагов почти нет, зато страница едет.
4. Главы не занимают никакой реальной дистанции страницы, поэтому пропуск главы структурно возможен.

## Новая механика: chapter = функция scrollY

Убрать перехват колеса/свайпа полностью. Сцена ничего не блокирует, прокрутка страницы остаётся родной.

### Геометрия трека

```text
CHAPTER_VH   = 85           // дистанция на главу
LEAD_VH      = 25           // вход сцены до первой главы
TAIL_VH      = 25           // выход сцены после последней
track height = LEAD + 4*CHAPTER + TAIL = 390vh
sticky scene = top-16, h-[calc(100vh-4rem)]
```

### Активная глава

```text
pinnedLen = trackHeight - sceneHeight
raw       = (scrollTop - trackTop - LEAD_px) / CHAPTER_px
index     = clamp(floor(raw), 0, 3)
localT    = raw - floor(raw)            // 0..1 внутри главы
```

Считать в `requestAnimationFrame` по `scroll`-событию (один rAF-тик, без throttle-таймеров). Никаких таймеров фаз, никакого reducer-lock: индекс всегда однозначно определён позицией страницы, пропуск главы невозможен.

### Анимация карточки по `localT`

- `0.00–0.14` — вход: opacity 0→1, translateY 16→0 (ease-out);
- `0.14–0.86` — удержание: opacity 1, translateY 0 (≈61vh прокрутки статичной карточки — это и есть «остановка»);
- `0.86–1.00` — выход: opacity 1→0, translateY 0→−16.

Значения вычисляются напрямую из `localT` (интерполяция в JS, inline-style), без CSS-`transition` — поэтому карточка не «улетает» и всегда соответствует позиции скролла, включая обратную прокрутку.

`prefers-reduced-motion`: только opacity, без translateY, границы фаз те же.

### Рендер и наложения

- Один узел `[data-story-card]`, контент из `chapters[index]`. Смена контента происходит в кадре, где `opacity ≈ 0` (границы фаз выхода/входа совпадают), поэтому два состояния не пересекаются визуально.
- Колонка: `storyColumnClass(chapters[index].id)` — как сейчас.
- Интервал и название — в фиксированном слоте у шкалы, вне анимируемой карточки.
- Зоны и ширина шкалы `axisWidth(chapter)` — как сейчас, только с `transition-[width] 320ms`.

### Ползунок

`onValueChange(i)` → `window.scrollTo({ top: trackTop + LEAD_px + (i + 0.5) * CHAPTER_px, behavior: "smooth" })`. Значение ползунка — производное от `index`, отдельного состояния нет.

### Удалить

`storyMachine.ts`, `storyMachine.test.ts`, `useReducer`, `machineRef`, фазовые таймеры, `EXIT_MS/ENTER_MS/HOLD_MS/GESTURE_GAP_MS/WHEEL_THRESHOLD/SWIPE_THRESHOLD`, обработчики `wheel/touchstart/touchmove/touchend/keydown`, `isPinned`, `canStep`, `step`, `IntersectionObserver` первого запуска.

## Критерии приёмки (scripts/test_longevity_scroll.py, 390×844 / 768×1024 / 974×738 / 1440×900)

1. Непрерывная прокрутка вниз через сцену тремя скоростями (`d=300/100ms`, `d=200/400ms`, `d=120/1200ms`) даёт последовательность глав ровно `1 → 2 → 4 → 6`; ни одна не пропущена ни на одной скорости.
2. Прокрутка вверх даёт `6 → 4 → 2 → 1`.
3. Каждой главе соответствует ≥ 55vh прокрутки, на которой opacity = 1 и translateY = 0 (карточка неподвижна).
4. В DOM всегда ровно один `[data-story-card]`; в кадре смены контента opacity ≤ 0.05.
5. Прокрутка страницы никогда не блокируется: за каждый жест колеса `scrollY` меняется (нет захвата).
6. Шкала, активный интервал и текст карточки всегда показывают одну главу.
7. `overflow-x = 0`, page errors и React-предупреждений от LifeTimeline нет.

## Границы изменений

Меняется только механика скролл-сцены. Тексты глав, иллюстрации, зоны, кризисная выноска, блок персон, пилюли и поп-апы не трогаю.

# Презентация «Landing Deck 2» на основе /landing2

Новая страница `/landing-deck-2` — версия /landing2 в формате презентации: каждый блок = один слайд 16:9 на весь экран, листается стрелками, выгружается в PDF одной кнопкой. Оригинальные /landing, /landing2 и /landing-deck не меняются.

## Состав слайдов (по порядку)

1. Первый экран (ПРОФИТ, как на /landing2)
2. «У каждого своё „болит“»
3. «Курс подойдёт тем, кто хочет» — 8 пунктов с иконками
4. Об авторе (Василий) + пара отзывов
5. **Три ступени** — одна лестница на один экран (см. ниже)
6. «Все 3 ступени»: пазл из 6 модулей + срок 11 недель + цена 140 000 → 69 000 руб. и «до 1 октября»
7–12. Шесть модулей — по одному слайду, с подписью ступени в углу
13. Как проходит обучение (эфиры, записи, вопросы)
14. Кейс Юлии
15. Результаты
16. Отзывы (без Светланы и Сергея)
17. Финальный слайд «Готовы построить фундамент капитала?»

Блок «Тарифы» в презентации отсутствует, как и на /landing2.

## Ступени: как уместить в один экран

- Три карточки в один ряд, основания выровнены по одной линии, верх уходит вверх ступенями слева направо.
- В каждой: крупная контурная цифра фоном, название, длительность, старая цена зачёркнута, новая цена акцентом, подпись «до 1 октября». Без списков и без кнопок «Заказать» (в PDF кнопки не нажимаются — вместо них на финальном слайде остаётся один призыв).
- Четвёртый вариант «Все 3 ступени» вынесен на следующий слайд с пазлом, чтобы лестница дышала.
- Разделители ступеней на слайдах модулей: не отдельные экраны, а метка «1 ступень · Ленивый бюджет» в шапке слайда модуля — так в PDF не появляется 3 почти пустых страницы.

## Адаптация

- Десктоп: ровно один слайд в экран, прокрутка с прилипанием, стрелки/пробел.
- Планшет и телефон: обычная вертикальная страница с нормальными отступами, лестница разворачивается в столбик, кнопка PDF остаётся.
- PDF: каждый слайд — страница 1920×1080; проверю, что ни один текст не обрезан и лестница целиком попадает на страницу.

## Техническая часть

- Новый файл `src/pages/LandingDeck2.tsx` — копия структуры `LandingDeck.tsx` (те же `slideCls`/`slideAttrs`, `SNAP_BASE`, `PDF_SLIDE_STYLE` 1280×720, `RevealList`), наполнение берётся из `Landing2.tsx`: audience, goalTasks с иконками, `CardAbout` (с `hideEducation`), ступени из `ProfitLevels`-данных, `PuzzleWeeks`, модули (`programWeeks` с «Модуль N»), кейс Юлии, `resultCategories`, отзывы без Светланы и Сергея.
- Данные ступеней вынести в `src/data/profitLevels.ts` (number, title, duration, oldPrice, price, href), чтобы `ProfitLevels.tsx` и новый дек использовали один источник; сам `ProfitLevels.tsx` только переключается на импорт — визуал /profit и /landing2 не меняется.
- Для лестницы в деке отдельный компонент `src/components/landing/StairsSlide.tsx` с фиксированной геометрией под 1280×720 (`items-end`, три фиксированные высоты), используется и в деке, и в PDF-режиме.
- `generateDeckPdf` получает необязательный параметр `page: "deck" | "deck2"` (по умолчанию `deck`) и по нему динамически импортирует нужную страницу; имя файла `profit-kp-2`.
- Маршрут `/landing-deck-2` в `src/App.tsx`; страница остаётся вне `sitemap`/`prerender` (как текущий дек) и с `noindex`, если он там стоит.
- Проверка Playwright на 1440×900, 1280×720, 768×1024, 390×844: по одному слайду в экран на десктопе, без горизонтальной прокрутки, без ошибок; плюс прогон `?pdfPreview=1` и скриншоты каждого слайда для контроля обрезаний.

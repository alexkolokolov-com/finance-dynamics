# Колесо сфер жизни: единый стиль иллюстрации + компактные ползунки

## Что не так сейчас
- В центре диаграммы стоит фотография эксперта — это выбивается из стиля статьи.
- Иконки сфер — тонкие линейные пиктограммы из UI-набора, а не тот рисованный стиль, что на исходной иллюстрации (девушка в позе лотоса, кружки-иконки: сердце, книга, дом, семья, чемодан, часы).
- Блок ползунков перегружен: иконка + название + цифры + две шкалы на каждую из 8 сфер = много линий и визуального шума.

## Что делаем

### 1. Центр диаграммы
Вместо фото эксперта — рисованная фигура человека в том же стиле, что на исходной иллюстрации: девушка сидит в позе лотоса, тонкий контур, кремовый фон, терракотовые акценты. Генерируем как PNG с прозрачным фоном и ставим в «дырку» в центре колеса, без обводки и без кружка-рамки, с запасом по месту, чтобы полигоны не резали фигуру.

### 2. Иконки сфер
Генерируем набор из 8 иконок в стиле исходной иллюстрации (тонкий рисованный контур, peach-кружок, терракотовый акцент): здоровье, образование, жильё, семья, впечатления, время на себя, отношения, финансы. Ставим их по концам осей вместо lucide-иконок, под каждой — короткая подпись и значения «важность / результат».

### 3. Блок ползунков — облегчаем
- Убираем иконки полностью.
- Одна строка на сферу: название слева, значения справа, под ними одна общая дорожка с двумя ползунками (важность — тёмный, результат — терракотовый), без разделительных линий между строками — вместо `divide-y` тонкий вертикальный ритм и чуть больше межстрочного воздуха.
- Подпись-легенда одна на весь блок, вверху («важность / результат»), без дублирования внизу.
- Компактнее по высоте, чтобы колонка ползунков совпадала по высоте с диаграммой на десктопе.

### 4. Раскладка
Оставляем как есть: десктоп — диаграмма 2/3 слева, ползунки 1/3 справа; мобильный — колонка. На мобильном диаграмма получает больше места за счёт уменьшенных подписей.

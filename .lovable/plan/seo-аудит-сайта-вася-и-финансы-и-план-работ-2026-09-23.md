# SEO-аудит сайта «Вася и финансы» и план работ

## Что проверил

В сайте 29 страниц-маршрутов. Проверил: меню на каждой странице, заголовки и описания для поиска, карту сайта, robots.txt, выдачу готового HTML для роботов.

## Найденные пробелы

**1. Меню пропадает на части страниц**
- Верхнего меню нет совсем на: «Сопровождение 2026» (`/support-2026`) и на двух страницах-презентациях (`/landing-deck`, `/landing-deck-2`), а также на старой версии главной (`/old`).
- В самом меню сайта нет ссылок на важные страницы: «Профит», «Лекции», «Бизнес-решения», «Переговоры», «Мероприятие», «Калькулятор», «Финансовое долголетие». То есть робот, придя на такую страницу, не видит пути ни туда, ни обратно.
- В подвале всего две ссылки («Главная» и «Марафон») — это главный источник внутренних ссылок для робота, и он почти пустой.

**2. Карта сайта неполная**
Отсутствуют: `/landing`, `/landing2`, `/support-2026`, `/traffic`, `/old`. Плюс в ней перечислены страницы, которые в поиск отдавать не нужно (служебные лендинги и тестовые). Нужно разделить: что индексируем, что нет.

**3. Готовый HTML для роботов отдаётся не для всех страниц**
Пре-рендер (он делает из страницы обычный HTML-файл) настроен на 26 адресов, но пропущены `/landing2` и обе презентации. Служебные страницы правильнее не пре-рендерить, а закрыть от индексации.

**4. Нет заголовка и описания у части страниц**
Свой заголовок вкладки и описание отсутствуют на: «Консультации», «Лекции», «Отзывы», «Сопровождение», «Сопровождение 2026», `/landing2`, `/traffic`. Они наследуют общий текст главной — для поиска это дубли.

**5. Нет canonical и разметки организации**
canonical подставляется только при сборке и только в пре-рендере; разметки Organization (JSON-LD) на сайте нет — её любят и Яндекс, и AI-ассистенты.

**6. Что уже хорошо**
robots.txt открыт для всех поисковиков и AI-ботов, включая Яндекс; проверочные файлы Яндекса и Google на месте; og-картинка и превью для соцсетей настроены; быстрая проверка основ прошла без замечаний.

## План работ

1. **Меню везде.** Добавить верхнее меню на `/support-2026` и `/old`. Презентации (`/landing-deck`, `/landing-deck-2`) оставить без меню, но закрыть от индексации — это КП для показа, не страницы сайта.
2. **Расширить навигацию.** В верхнем меню — «Профит» рядом с «Сопровождением»; в подвале собрать полный список разделов: услуги (консультации, сопровождение, профит, для компаний, лекции), материалы (кэшбэк-гайд, чек-лист, калькулятор), блог со статьями, отзывы, оферта. Это даст роботу сквозные ссылки с любой страницы.
3. **Заголовки и описания.** Прописать уникальный заголовок и описание для семи страниц из списка выше — с ключевыми словами по теме страницы.
4. **Карта сайта.** Пересобрать: включить все публичные страницы (добавить `/landing`, `/profit` уже есть, `/support-2026`), исключить служебные (`/landing2`, `/landing-deck*`, `/traffic`, `/old`). Каждой странице — приоритет по смыслу.
5. **Закрыть служебное.** Для `/landing2`, `/landing-deck`, `/landing-deck-2`, `/traffic`, `/old` — запрет индексации (в robots.txt и мета-тегом), чтобы они не конкурировали с основными страницами.
6. **Пре-рендер под карту сайта.** Привести список адресов пре-рендера в точное соответствие карте сайта, чтобы каждый индексируемый адрес отдавался готовым HTML.
7. **Разметка для поиска и AI.** Добавить Organization/Person JSON-LD на главную, разметку статьи на страницы блога, canonical на каждую страницу.
8. **Проверка.** После правок: собрать проект, убедиться, что для каждого адреса из карты сайта создан HTML-файл с полным текстом, пройти по сайту как робот (только по ссылкам) и подтвердить, что все страницы достижимы и меню не теряется.

## Что дальше

После этого карту сайта можно отдавать в «Яндекс.Вебмастер» и Google Search Console — адрес будет `https://vasyaifin.ru/sitemap.xml`. Изменения в HTML попадут на живой сайт после публикации.

# Дерево роста доходов — согласование содержания

Из вашего файла извлечена структура: 3 категории (ветви) и 4 уровня вложенности. Ниже полный текст — проверьте формулировки, потом делаю иллюстрацию/схему вместо текущей картинки `plan-mindmap.jpg` на `/financial-plan`.

Общая рамка (над деревом): «Максимизация эффективности текущих доходов» · «Финансовый план на 5–10 лет».

## Категория 1. НАЙМ

**Текущая карьера**
- Карьерный план: самостоятельно / консультант / тренинги
- Ментор (подойдёт всем): на текущей работе / вне работы / контакты менторов
- «Разговор с руководителем»: «Деньги» / «Развитие» / «Обстоятельства»

**Альтернативная карьера**
- Карьерный план: консультант
- hh.ru / Executive search: список агентств и сайтов / спросить у того, кто ушёл
- Бывшие коллеги: актуально и для тех, кто работает на себя (партнёры, конкуренты)

**Новая профессия**
- Аналитик данных
- IT: получается у 2–3 из 10, но зарплата 300К+

## Категория 2. НА СЕБЯ

**Фриланс / работа на себя**
- План на 5–10 лет
- Нетворкинг: минимум 1 новый контакт в неделю; форумы, выступления, соцсети
- «Фоном» смотреть, где можно консультировать; сделать визитку себя/бизнеса

**Бизнес**
- Нужно выбирать одно направление
- Партнёрства

**Социальные инструменты**
- Экспертный блог: Telegram, соцсети, платформы услуг, инфопродукт или реклама
- Форумы / мастермайнды
- Друзья: общаться про деньги, дружба и партнёрство, кофе раз в 2 недели

## Категория 3. ОБЩИЕ

**Инструменты в бюджете**
- Что актуально через 5 лет? Сколько часов в неделю перерабатываешь?
- Базовое: НДФЛ-вычеты, кешбэки, ИИС, ДМС
- Финансовые услуги как инструмент: 20–30 тыс/мес при работе 2 ч/день

**Монетизация хобби**
- Тематические сообщества: активность — поиск партнёров и клиентов
- Монетизация обучений: план монетизации ДО начала обучения
- Бизнес

**«Государство»**
- Гранты: учёные, для детей, стартапы
- Тендеры

**Творчество**
- Выступления
- Книги / музыка

**Семья**
- Поиск мужа (как в исходнике)
- Детские каналы / контент

## Решения по вопросам

1. Бренды, имена и сервисы не упоминаем — формулировки обезличены, как в тексте выше.
2. «Поиск мужа» оставляем как в исходнике.
3. Делаем схему кодом (без растровой картинки), с продуманной мобильной адаптацией.

## Адаптация

- Десктоп (≥1024px): три колонки-ветви (НАЙМ / НА СЕБЯ / ОБЩИЕ) в одном кремовом фрейме, все уровни раскрыты. Заголовок ветви — терракотовая пилюля; блоки 2-го уровня — карточки; 3-й уровень — список с тонкой левой линией; 4-й уровень — мелкие подписи под пунктом.
- Планшет (640–1023px): две колонки, ветви перетекают; всё так же раскрыто.
- Мобильный (<640px): одна колонка, каждая ветвь — аккордеон (по умолчанию раскрыта первая, остальные свёрнуты), внутри блоки 2-го уровня идут вертикально; 3–4 уровни без отступов-лестницы, чтобы не было горизонтального скролла. Тап по всей строке заголовка, шрифты на пункт меньше, компактные вертикальные интервалы.
- Никакого горизонтального скролла и мелкого нечитаемого текста: минимальный размер 14px, длинные слова с переносами.

## Технически

- Новый компонент `src/components/article/IncomeTree.tsx`: данные деревом в одном массиве, рендер 3 ветвей → блоки 2-го уровня → пункты 3-го → подписи 4-го уровня.
- Аккордеон на мобильном — локальный state + `useMediaQuery`/CSS (details/summary как fallback), на десктопе состояние игнорируется и всё открыто.
- Стили — только токены бренда (кремовый фон, терракота для акцентов ветвей), Outfit/Figtree, неразрывные пробелы через `nbsp()`.
- В `src/pages/FinancialPlan.tsx` заменить `<Figure src={mindmapImg} …>` на `<IncomeTree />` с подписью, импорт `plan-mindmap.jpg` удалить.
- Проверка через Playwright: скриншоты на 1280, 820 и 390px.
